# POWER CHARGE

Webカメラの前で体を動かしてエネルギーを貯め、ロケットを打ち上げるブラウザゲーム。
**3秒カウントダウン → 45秒チャージ → 10秒発射演出 → 結果・TOP10**。

## 起動

Node.js 20以降がある場合、プロジェクトのフォルダで：

```sh
npm start
```

http://localhost:4174 を開き、STARTでカメラを許可してください。依存パッケージのインストール、APIキー、ログイン、バックエンドは不要です。

Pythonでも起動できます：

```sh
python3 -m http.server 4174 --bind 127.0.0.1 --directory dist
```

`index.html`を直接開く `file://` では、カメラとWeb Workerが動作しません。別の端末へ配信する場合はHTTPSが必要です。`dist/` 全体を静的ホスティングに配置できます。MediaPipeの `.wasm` / `.mjs` / `.task` も含めてください。

## 会場での使い方

- PC＋Webカメラ＋16:9のモニターを基本としています。全画面ボタンで拡大できます。
- 頭・肩・腰・膝が映り、認識が1.5秒安定すると自動でカウントダウンします。
- 膝が映らない場合は「上半身でプレイする」が表示されます。頭・肩・腰は映してください。
- 腕だけでも十分に得点できます。ジャンプとスクワットは任意です。
- カメラは固定してください。周囲をあけ、明るい場所で1人ずつプレイしてください。
- 音は初期状態でOFF。右上のSOUNDで有効にできます。
- 「中断」またはEscで一時停止。2秒の認識喪失やタブの非表示でも停止します。
- 再開時はカメラ内に戻り「つづける」。カメラ切断時は再接続画面になります。
- 結果画面で8文字までの名前を記録。スキップはPLAYER名で記録します。
- TOP10はそのブラウザのlocalStorageに保存されます。プライベートブラウズ、データ削除、ブラウザ変更では保持されない場合があります。
- 飛距離とランクはゲーム内の演出値で、現実の飛行シミュレーションや身体能力の測定ではありません。

## 実装

- HTML / CSS / ES modules / Canvas / Web Camera API。ビルド不要。
- MediaPipe Tasks Vision **0.10.21**、Pose Landmarker Lite float16 v1をローカル同梱。
- Web Workerで最大約20fpsの姿勢推定。フレームを積み上げず、直前の処理完了を待って次のフレームを渡します。
- 画面描画は独立したrequestAnimationFrame。カメラ映像と骨格は同じ座標変換で左右反転。
- 手首・肘・肩・腰・膝の変位を胴体長で正規化。平滑化、デッドゾーン、信頼度フィルター、認識の再取得時のリセットを適用。
- 全身の剛体的な一斉移動はカメラの揺れとして抑制。これにより体ごとの移動も一部抑制されます。
- HAND +50、SQUAT +100、JUMP +150。連発防止のクールダウンあり。HANDは両手首と両肘の大きな動きを条件とし、1.8秒クールダウン。
- スクワットは足首に対する腰の下降→上昇。ジャンプは予備動作、頭・肩・腰・足首の上昇、下降を確認します。フォーム評価は行いません。
- FULL POWERは腕・胴体・膝の同時運動で3秒間×1.5。6秒クールダウン。
- コンボは活動0.5秒ごとに増加、停止2秒でリセット。通常加点倍率は最大×1.4。
- 9999 POWERで上限。0/1500/3000/5000/7000/8500/9500の境界で大空/成層圏/宇宙/月/火星/木星/太陽系突破。
- 描画の揺れや粒子は `prefers-reduced-motion` に対応。画面全体の激しい点滅はありません。

## プライバシーとオフライン

映像・画像・骨格データはブラウザ内のみで処理し、保存・送信しません。マイクは要求しません。外部CDN、外部フォント、解析・広告SDKへの実行時アクセスはありません。ローカルサーバーからモデルを含むすべてのファイルを配信するため、インターネットなしでも動作する構成です。

同梱物の出典とライセンスは [THIRD_PARTY.md](THIRD_PARTY.md) を参照してください。

## 難易度調整（ルールV2）

- 動いたというだけの基本点を撤廃。手首だけの小さな動きではほとんど加点されません。
- 直近0.65秒の移動範囲を胴体長で正規化し、速く細かく振るだけでは高得点にならないようにしています。
- 手首の重みを低く、肘・肩・腰・膝の重みを高く設定。範囲と速度の両方で通常加点を決めます。
- HAND BOOSTとFULL POWERにも動作範囲の条件を追加。SQUAT BOOSTの腰の上下幅と往復時間も引き上げています。
- 腕全体を大きく使えば、ジャンプなしでも高得点を狙えます。動作範囲を広げる際も周囲に注意し、無理のない範囲で遊んでください。
- これはゲームの配点であり、身体負荷・消費カロリー・運動能力の測定ではありません。
- 新ランキングは `power-charge.top10.v2` に保存。旧 `v1` のデータは消さず、異なる配点の記録を混ぜません。
- 比較テストは合成骨格を使っています。実際の照明、体格、カメラ条件での難易度は会場機材で確認してください。

## 検証

```sh
npm test
npm run check
```

`tests/` は段階別の自動テストです。カメラのモック、合成骨格、時刻、保存領域を使って、キャンセル処理、微小ノイズ除去、Movement Score、POWER、45秒の進行、各ボーナス、コンボ、飛行境界、ランキング、リプレイまで確認します。通しテストでは実際のアプリ制御と画面要素への値の反映を確認します。

**未検証：** 実カメラでのMediaPipe推論精度・処理速度、ブラウザでの実描画、会場の照明・距離・カメラ条件による体験。この制作環境では操作可能なブラウザ/カメラが提供されていません。自動テストの成功は実機検証の代替ではありません。

展示前に次を実機で確認してください：

1. カメラ許可後に頭〜足首の骨格が重なり、鏡像と一致する。
2. 静止時は加点されず、腕の動きに遅れなくPOWERが増える。
3. 手振り・上下運動で該当ボーナスが出る。ジャンプなしでも遊べる。
4. カメラ外へ移動→一時停止→復帰、タブ移動、カメラ切断を試す。
5. 45秒終了→10秒演出→結果、記名/スキップ保存→もう一度遊ぶ。
6. 会場モニターの全画面で文字、映像、結果入力が切れない。

性能に合わせた調整箇所：`dist/lib/pose.mjs` の推論間隔、`movement.mjs` のデッドゾーン、`charge.mjs` の配点、`bonuses.mjs` のしきい値。画面と演出は `style.css` / `scene.mjs`。
